How This Should Work

1. Maker posts availability

The listing states side, min/max fill, price rule, response window, confirmation policy, and whether a local agent is watching.

2. Taker reserves terms

The selected size is reserved briefly. The maker is notified before any wallet action is required.

3. Room opens

The parties continue in a P2P room or an atomic swap room, depending on the offer's settlement mode.

4. Wallets sign locally

Bob Wallet and BTC wallets show exact terms before signing. Liquidity.spot records public progress only.

Settlement Options

Human P2P room

Local liquidity agent

Build Checklist

  1. Add a standing-offer model with side, min/max size, price rule, availability, reservation window, and settlement mode.
  2. Add reservation state so takers can hold an offer briefly without pretending funds are locked.
  3. Send maker notifications through Bob Wallet, email, Telegram, or the dashboard.
  4. Convert accepted reservations into P2P rooms first, then atomic swap rooms after the wallet-assisted flow is proven.
  5. Add local agent policies only after manual maker mode has real usage data.
