Open Source

Liquidity.spot is open source.

We are building Liquidity.spot in public so the Handshake community can inspect it, improve it, and build new non-custodial liquidity tools on top of it.

View GitHub Repo Read The Tutorial

Inspect The Flow

Review how offers, trade rooms, callbacks, and experimental atomic-swap screens work before trusting them with real coordination.

Contribute Safely

Small, focused improvements to docs, guest-mode UX, trade safety copy, tests, and wallet helper interfaces are especially welcome.

Build On It

Fork the project, adapt it for new liquidity flows, or use the patterns here as a starting point for other Handshake coordination tools.

What We Want Help With

P2P trade safety

Clearer milestones, better warnings, stronger dispute context, and less room for user error.

Wallet integrations

Conservative helpers for Bob Wallet and Bitcoin wallets that never request seeds, private keys, or wallet passwords.

Testing and review

Regression tests around offer creation, trade state changes, guest accounts, and experimental swap callbacks.

Docs for builders

Setup guides, API notes, deployment notes, and examples that make it easier for contributors to get moving.

Experimental Software

Liquidity.spot is a coordination layer, not a custodian. The project is early, and users should independently verify counterparties, addresses, transaction IDs, and settlement before releasing any asset.
