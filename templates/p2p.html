Primary Mode

Human P2P Swaps

This is the safer near-term direction for `Liquidity.spot`: a non-custodial, human-to-human marketplace for coordinating HNS/BTC swaps.

The platform helps counterparties find each other, agree on price, understand Alice/Bob roles, and track trade progress without pretending the current atomic-swap execution flow is mainnet-ready.

What This Mode Means

  • Human-to-human matching and negotiation
  • Shared trade room and milestone tracking
  • TXID submission, notes, and confirmations
  • Reputation and Gems as accountability tools
  • No platform custody of user funds

Build Status

  • Concept approved as the main product direction
  • Trade-room UX still to be built
  • Milestones, chat, disputes, and TXID flow coming next
  • Trustless atomic swap flow remains available separately in testing mode

Near-Term Product Plan

Phase 1

  • P2P trade room
  • Milestone checklist
  • Manual TXID submission
  • No-show / cancel flows

Phase 2

  • Disputes and moderation tools
  • Gems stake and penalty rules
  • Counterparty notes / chat
  • Explorer verification support

Note: The current HTLC-based trustless swap screens are still useful for testing and learning, but they remain experimental. Human P2P is intended to become the main production-facing path.
